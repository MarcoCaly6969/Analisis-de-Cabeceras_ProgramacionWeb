Introducción a Python

¿Qué es Python?

Python es un lenguaje de programación de alto nivel, conocido por tener una sintaxis sencilla y fácil de aprender.

Primer programa


print("Hola mundo")

Variables

Las variables permiten almacenar información que podemos utilizar durante la ejecución de un programa. 


nombre = "Marco"
edad = 20
altura = 1.75

En este ejemplo se almacenan un nombre, una edad y una altura.

Condicionales

Los condicionales permiten ejecutar diferentes instrucciones dependiendo de una condición. 


edad = 18

if edad >= 18:
    print("Es mayor de edad")
else:
    print("Es menor de edad")

Bucles

Bucle for

El bucle for permite repetir una acción varias veces. 


for i in range(5):
    print(i)

Bucle while

El bucle while repite instrucciones mientras una condición sea verdadera. 


contador = 0

while contador < 5:
    print(contador)
    contador += 1

Funciones

Una función es un bloque de código que podemos reutilizar para realizar una determinada tarea. 


def saludar(nombre):
    print("Hola", nombre)

saludar("Marco")

Consejo

La mejor forma de aprender Python es practicar escribiendo pequeños programas y modificando los ejemplos.
