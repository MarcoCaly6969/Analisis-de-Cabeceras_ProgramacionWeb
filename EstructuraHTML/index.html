1. Qué es Python y para qué se utiliza

Python es un lenguaje de programación: permite escribir instrucciones que una computadora puede ejecutar. Su sintaxis es legible y facilita aprender conceptos básicos. Se utiliza en automatización, análisis de datos, inteligencia artificial, aplicaciones web y proyectos científicos.

Un programa puede realizar un cálculo y mostrar su resultado. print() muestra información en pantalla. Las líneas que comienzan con # son comentarios: explican el código y no se ejecutan.

# Calcular el total de una compra
print(3 * 15)  # Muestra 45

2. Cómo instalar Python

Utiliza una versión estable de Python 3. Descárgala desde el sitio oficial: https://www.python.org/downloads/. Evita versiones de prueba para comenzar.

En Windows

  1. Descarga el administrador de instalación de Python (Python Install Manager) desde el sitio oficial e instálalo.
  2. Abre una terminal nueva, como PowerShell, y ejecuta py install 3 para instalar una versión estable de Python 3.
  3. Comprueba la instalación con py --version.
  4. Escribe py para abrir el intérprete interactivo, donde puedes ejecutar instrucciones de Python.

En macOS

  1. Descarga el instalador de Python 3 para macOS desde el sitio oficial.
  2. Abre el archivo .pkg y sigue las indicaciones del instalador.
  3. Abre Terminal y ejecuta python3 --version para comprobar la instalación.
  4. Escribe python3 para abrir el intérprete interactivo.

En Linux

Comprueba primero si Python ya está instalado ejecutando python3 --version en la terminal. Si no lo está, utiliza el gestor de paquetes de tu distribución. Por ejemplo, en Ubuntu o Debian puedes ejecutar los siguientes comandos de terminal:

sudo apt update
sudo apt install python3

Después, escribe python3 para abrir el intérprete. En cualquier sistema, verás el indicador >>>: señala que Python espera una instrucción. No copies ese indicador al escribir los ejemplos.

Prueba este código dentro del intérprete:

print("Python está funcionando")

Para salir del intérprete, escribe exit(). Los comandos de instalación se ejecutan en la terminal, no dentro de Python. Puedes consultar las instrucciones oficiales para Windows en https://docs.python.org/3/using/windows.html.

3. Primer programa con print("Hola mundo")

Un programa es una secuencia de instrucciones. La función print() muestra un mensaje; las comillas indican que el contenido es texto.

print("Hola mundo")

La salida será Hola mundo. Para guardar un programa, escribe el código en un editor de texto y guárdalo, por ejemplo, como hola.py. La extensión .py identifica un archivo de Python. Este archivo de práctica lo creas tú; no forma parte de los tres archivos del proyecto.

Abre la terminal en la carpeta donde guardaste el archivo y ejecuta py hola.py en Windows o python3 hola.py en macOS y Linux. También puedes probar instrucciones individuales directamente en el intérprete.

4. Variables

Una variable es un nombre que hace referencia a un valor. El operador = asigna un valor a ese nombre. No necesitas declarar el tipo previamente y puedes cambiar el valor durante la ejecución.

nombre = "Ana"
edad = 18
print(nombre)  # Ana
print(edad)    # 18

edad = edad + 1
print(edad)    # 19

Utiliza nombres descriptivos, como nota_final. No pueden comenzar con un número ni contener espacios. Python distingue mayúsculas de minúsculas: edad y Edad son nombres diferentes. = asigna; no sirve para comparar igualdad.

5. Tipos de datos: int, float, str y bool

El tipo de un dato determina qué clase de valor representa y qué operaciones permite.

  • int: números enteros, como 20 o -3.
  • float: números con parte decimal, como 8.5. En el código se usa punto decimal.
  • str: texto entre comillas, como "Universidad".
  • bool: valores lógicos, True o False, escritos con mayúscula inicial.
cantidad = 20          # int
promedio = 8.5         # float
materia = "Python"    # str
esta_inscrito = True  # bool

print(type(cantidad))       # <class 'int'>
print(type(promedio))       # <class 'float'>
print(type(materia))        # <class 'str'>
print(type(esta_inscrito))  # <class 'bool'>

La función type() permite consultar el tipo de un valor. El número 20 y el texto "20" son distintos: el primero permite cálculos directamente; el segundo representa caracteres.

6. Operadores aritméticos, relacionales y lógicos

Los operadores permiten calcular valores y construir condiciones.

Operadores aritméticos

Se utilizan para realizar cálculos: + suma, - resta, * multiplicación, / división, // división entera, % resto y ** potencia. La división entera redondea el cociente hacia abajo; por ejemplo, -7 // 2 resulta en -4.

a = 7
b = 2
print(a + b)   # 9
print(a - b)   # 5
print(a * b)   # 14
print(a / b)   # 3.5
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 49
print((a + b) * 2)  # 18

Los paréntesis ayudan a indicar el orden de las operaciones. No es posible dividir entre cero.

Operadores relacionales

Comparan valores y producen un resultado booleano: == igual, != distinto, > mayor, < menor, >= mayor o igual y <= menor o igual.

nota = 75
print(nota == 75)  # True
print(nota != 75)  # False
print(nota > 80)   # False
print(nota < 80)   # True
print(nota >= 60)  # True
print(nota <= 100) # True

Operadores lógicos

and exige que ambas condiciones sean verdaderas. or exige que al menos una sea verdadera. not invierte el valor lógico de una condición.

edad = 19
tiene_credencial = True
print(edad >= 18 and tiene_credencial)  # True
print(edad < 18 or tiene_credencial)    # True
print(not tiene_credencial)            # False

7. Entrada de datos utilizando input()

input() muestra una pregunta, espera a que escribas una respuesta y la devuelve como texto. Para hacer cálculos, convierte ese texto con int() o float().

nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))
altura = float(input("¿Cuánto mides en metros? Ejemplo: 1.70: "))

print("Hola,", nombre)
print("El próximo año tendrás", edad + 1, "años")
print("Tu altura es", altura, "metros")

Si escribes Ana, 18 y 1.70, el programa te saluda e indica que tendrás 19 años. Introduce un entero para la edad y usa punto para los decimales. Si intentas convertir texto no numérico, como "dieciocho", obtendrás un error ValueError. Por ahora, los ejemplos suponen entradas numéricas válidas.

8. Condicionales if, elif y else

Los condicionales permiten elegir qué instrucciones ejecutar. if evalúa la primera condición; elif comprueba otra si la anterior fue falsa; else se ejecuta cuando ninguna condición anterior se cumple.

En este ejemplo didáctico, las notas van de 0 a 100 y se aprueba desde 60. Es una regla del ejercicio, no una norma de tu universidad.

nota = 85

if nota >= 90:
    print("Excelente")
elif nota >= 60:
    print("Aprobado")
else:
    print("Necesitas reforzar el tema")

La salida es Aprobado. Python evalúa las condiciones en orden y ejecuta solamente la primera rama que corresponde. Cada encabezado termina con : y su bloque se escribe con sangría de cuatro espacios. Esa sangría forma parte de la sintaxis.

9. Bucles for y while

Un bucle repite instrucciones. Usa for para recorrer elementos o una secuencia de números. Usa while para repetir mientras una condición sea verdadera.

Bucle for

range(1, 4) produce los números 1, 2 y 3. El límite final, 4, no se incluye.

for numero in range(1, 4):
    print("Repetición", numero)

El programa imprime tres líneas, una para cada número. range(3) también produce tres valores, pero empieza en cero: 0, 1 y 2.

Bucle while

contador = 1

while contador <= 3:
    print("Contador:", contador)
    contador = contador + 1

Este ejemplo muestra los valores 1, 2 y 3. La actualización del contador permite que la condición llegue a ser falsa. Si olvidas actualizarlo, el bucle puede ejecutarse indefinidamente. Ambos tipos de bucle requieren : y sangría.

10. Listas

Una lista guarda varios elementos en un orden y permite modificarlos. Se escribe entre corchetes, con sus elementos separados por comas. Las posiciones, llamadas índices, comienzan en cero.

notas = [70, 85, 90]
print(notas[0])  # 70: primer elemento

notas[1] = 88    # Modificar el segundo elemento
notas.append(95) # Agregar un elemento al final
print(len(notas))  # 4: cantidad de elementos

for nota in notas:
    print(nota)

Después de los cambios, la lista es [70, 88, 90, 95]. append() agrega un elemento y len() devuelve la cantidad de elementos. [] representa una lista vacía. Acceder a una posición inexistente produce un error IndexError.

11. Funciones

Una función reúne instrucciones que realizan una tarea y pueden reutilizarse. Se define con def, seguida de su nombre, paréntesis y :. Los parámetros son los nombres que reciben los datos de entrada. return devuelve un resultado y termina la ejecución de la función.

def calcular_promedio(nota1, nota2):
    promedio = (nota1 + nota2) / 2
    return promedio

resultado = calcular_promedio(80, 90)
print("Promedio:", resultado)  # Promedio: 85.0

Aquí, nota1 y nota2 son parámetros; 80 y 90 son los argumentos usados al llamar a la función. Definir una función no ejecuta su cuerpo: debes llamarla. print() muestra información, mientras que return entrega un valor que puedes guardar o utilizar en otro cálculo.

12. Ejercicio final: registro de notas

Crea un programa que pida el nombre de un estudiante y tres notas, guarde las notas en una lista, calcule el promedio mediante una función y muestre el resultado. Utiliza notas de 0 a 100. Para este ejercicio, un promedio de al menos 90 es excelente; desde 60 es aprobado; por debajo de 60 requiere refuerzo.

  1. Pide el nombre con input().
  2. Usa un for para solicitar tres notas y conviértelas con float().
  3. Usa un while para volver a pedir cualquier nota fuera del intervalo de 0 a 100.
  4. Guarda cada nota válida en una lista con append().
  5. Define una función que recorra la lista, acumule las notas y devuelva el promedio.
  6. Muestra el nombre, el promedio y una clasificación con if, elif y else.

Intenta resolverlo antes de leer la solución. Introduce valores numéricos finitos con punto decimal cuando sea necesario. El ejemplo valida el intervalo, pero no maneja entradas de texto no numéricas.

Solución orientativa

def calcular_promedio(notas):
    total = 0
    for nota in notas:
        total = total + nota
    return total / len(notas)

nombre = input("Nombre del estudiante: ")
notas = []

for numero in range(1, 4):
    print("Nota", numero)
    nota = float(input("Escribe un valor entre 0 y 100: "))

    while nota < 0 or nota > 100:
        print("La nota debe estar entre 0 y 100.")
        nota = float(input("Vuelve a ingresar la nota: "))

    notas.append(nota)

promedio = calcular_promedio(notas)

print("Estudiante:", nombre)
print("Notas registradas:", notas)
print("Promedio:", promedio)

if promedio >= 90:
    print("Resultado: excelente")
elif promedio >= 60:
    print("Resultado: aprobado")
else:
    print("Resultado: necesitas reforzar el tema")

La función recibe una lista que debe contener al menos una nota. En este programa, el for garantiza tres notas antes de llamarla, por lo que no se divide entre cero.

Comprobación manual

  • Con el nombre Ana y las notas 80, 90 y 100, el promedio es 90.0 y el resultado es excelente.
  • Con las notas 50, 60 y 70, el promedio es 60.0 y el resultado es aprobado.
  • Con las notas 40, 50 y 60, el promedio es 50.0 y el resultado indica que necesitas reforzar el tema.
  • Si escribes 120 o -5 como nota, el programa vuelve a pedirla antes de guardarla.

Como práctica adicional, cambia el programa para registrar cinco notas. Ajusta el límite de range() y comprueba que la función sigue calculando el promedio correctamente.

13. Conclusión

Ya conoces los elementos básicos para escribir programas: mostrar mensajes, almacenar datos, recibir entradas, realizar operaciones, tomar decisiones, repetir tareas, organizar listas y reutilizar instrucciones mediante funciones. Aprender a programar requiere práctica: modifica los ejemplos, predice sus resultados y compara tus predicciones con la ejecución.

Este último ejemplo resume cómo una función puede recorrer una lista y aplicar una condición:

def mostrar_aprobados(notas):
    for nota in notas:
        if nota >= 60:
            print("Nota aprobada:", nota)

mostrar_aprobados([45, 60, 85])

La salida muestra las notas 60 y 85. Como siguiente paso, practica con pequeños problemas y aprende a manejar errores de entrada antes de construir programas más grandes.
