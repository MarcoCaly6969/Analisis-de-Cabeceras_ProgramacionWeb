Prompt 2:
Mejora mi página HTML de un tutorial básico de Python. Conserva los textos y ejemplos de las secciones Introducción, Variables, Condicionales, Bucles, Funciones y Consejo.

Quiero un diseño ordenado, bonito y cálido, que parezca realizado por un estudiante. Evita un estilo demasiado simple, frío, empresarial o complejo. Utiliza colores inspirados en Python, combinando azul, amarillo suave, fondo crema y tarjetas claras, con bordes redondeados y sombras discretas.

Organiza la página siguiendo esta estructura:

* Un header en la parte superior con el título “Tutorial Básico de Python”, una breve descripción y una presentación acogedora.
* Un aside a la izquierda con el índice y enlaces internos a las cinco secciones.
* El main a la derecha con el contenido del tutorial, organizado mediante section y article.
* Un footer debajo de ambas columnas con el texto “Tutorial básico de Python - 2026”.

Aplica Mobile First: el CSS base debe estar pensado para celulares en posición vertical, con una sola columna, padding lateral y texto legible. En celular, coloca el índice encima del contenido. En pantallas mayores, distribuye el índice a la izquierda y el tutorial a la derecha.

Mantén la etiqueta viewport y organiza las media queries con comentarios claros para:

* Mobile First y Mobile Portrait.
* Mobile Landscape: ajustar espacios y aprovechar el ancho horizontal.
* Tablet, desde 768px.
* Laptop, desde 1024px: contenido centrado y limitado mediante max-width.
* Print, mediante @media print.

Evita el desplazamiento horizontal de toda la página. Los bloques de código deben parecer pequeños editores, con fondo oscuro, texto claro, encabezado sencillo, bordes redondeados y overflow-x: auto cuando sea necesario. Puedes añadir colores a las palabras del código usando HTML y CSS, sin modificar los ejemplos.

Numera visualmente las secciones y destaca el consejo con un fondo amarillo suave. Mantén una separación equilibrada entre títulos, párrafos y ejemplos.

Al imprimir, oculta el índice, la navegación y los elementos decorativos. Usa fondo blanco y texto negro, conservando todo el contenido educativo y los ejemplos de código legibles.

Utiliza únicamente HTML5 semántico y CSS3 dentro de una etiqueta style en el mismo archivo. No utilices JavaScript, Bootstrap, Tailwind, frameworks ni librerías externas. Prioriza propiedades sencillas como margin, padding, flex, gap, width, max-width, colores, bordes y media queries, para que pueda explicar el código al docente.

Entrega el archivo index.html completo, desde <!DOCTYPE html> hasta </html>, listo para abrir en el navegador.
